# Weather App

A basic weather application built with **React.js** that allows users to search for a location and view its weather information.

## Features

* Search weather by city
* Display temperature
* Show weather conditions
* Simple and responsive interface
* API-based weather data

## Tech Stack

* React.js
* JavaScript
* CSS
* Weather API

## Run Locally

```bash
npm install
npm run dev
```

## Purpose

This project was built to practice React components, API integration, state management, user input, and asynchronous JavaScript.
